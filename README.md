# 把回忆拼好给你

一个用代码画出来的 27 秒横版 MV。画面做成工程蓝图，从等轴测残屋和水杯倒影，走到裂口金缮，再把修好的半张图纸当作相纸递出去。成片规格为 1920 × 1080、60 fps。

[观看成片](./%E6%8A%8A%E5%9B%9E%E5%BF%86%E6%8B%BC%E5%A5%BD%E7%BB%99%E4%BD%A0.mp4) · 配乐为王贰浪《把回忆拼好给你》的末段副歌。

## 用到的工具

| 工具 | 用途 |
|---|---|
| Remotion | 预览分镜、按帧控制动画、合成音轨并导出 MP4 |
| React、TypeScript、SVG | 用组件组织七个分镜，绘制蓝图线框、裂纹、金线和相纸动效 |
| HTML Canvas、Web Audio API | 做歌词对轴页，显示音频波形，支持定位、打点和导出 JSON |
| FFmpeg | 截取音频、抽帧对照转场、检查导出视频 |
| Python、NumPy、Pillow | 分析音频，生成纸纹、折痕和颗粒贴图 |
| faster-whisper | 本地识别人声，提取词级时间戳，作为歌词和切镜对轴的初稿 |

## 多模型协作

Claude Code 搭了初版分镜和 Remotion 工程。Codex 接手对轴、转场和渲染。通过 Agent HUD 把成片交给 Antigravity 里的 Gemini 审片，按它给出的具体时间点改了白裂口接金线、总图抬起相纸和片尾退场，再抽帧复核。

画面由代码绘制。这个仓库收录的是成片和制作说明。
